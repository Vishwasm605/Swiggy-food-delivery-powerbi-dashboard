# Swiggy-food-delivery-powerbi-dashboard

Overview

This project analyzes Swiggy food delivery operations using Power BI.
It provides insights into order trends, delivery performance, rider efficiency, and cancellation behavior.

Key Insights

* Peak order time occurs around **2 PM**
* Peak cancellation hour is **8 PM**
* Most deliveries are completed within **10–30 minutes**
* Longer distances slightly increase delivery time
* Cancellation rate spikes at late hours

Dashboard Features

* KPI Cards (Total Orders, Avg Delivery Time, Riders, Cancellation %)
* Order trends by hour
* Delivery time distribution
* Rider performance analysis
* Cancellation rate by hour
* Distance vs delivery time relationship

Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* SQL (for preprocessing)
* Data Visualization

Business Use Case

This dashboard helps:

* Identify peak demand hours
* Optimize delivery operations
* Improve rider allocation
* Reduce cancellations
